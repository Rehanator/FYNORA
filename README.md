# FYNORA

A full-stack web application combining a modern TypeScript frontend with a Python backend.

## 🛠️ Tech Stack

**Frontend:**
* **TypeScript** 
* **TanStack Start / React** (Framework)
* **Vite** (Build tool)
* **Bun** (Package manager & runtime)
* **shadcn/ui** (Component system via `components.json`)

**Backend & Tooling:**
* **Python** (Backend services/API)
* **ESLint & Prettier** (Code formatting and linting)

## 📁 Project Structure

* `/src` - Frontend TypeScript source code and UI components.
* `/backend` - Python backend logic, APIs, and scripts.
* `/public` - Static assets (images, icons, etc.).
